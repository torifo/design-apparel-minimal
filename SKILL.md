# design-apparel-minimal (FORM)

A landing-page **design study** for a fictional minimal-persona apparel brand ("FORM" — *"only what remains"*). Pure HTML + CSS custom properties + vanilla JS, GitHub-Pages ready, **no framework / no build**. Use this as a **style reference** when building a similar aesthetic.

架空のミニマル系アパレルブランド「FORM」の LP デザイン研究。純粋な HTML + CSS Custom Properties + Vanilla JS。同種の世界観を作るときの**スタイル参照**として使う。

## When to use / 使いどころ
- **EN:** designing a minimal / normcore / quiet-luxury site — fashion, apparel, or any "quality-over-quantity" brand targeting design-minded users. Architecture-studio-portfolio feel.
- **JP:** ミニマル／ノームコア／クワイエットラグジュアリーなサイト（アパレル等、量より質を訴求するブランド）。建築事務所ポートフォリオ的な静けさ。

## Design system / デザインシステム
- **Color / カラー:** pure white `#FAFAFA` × near-black `#111111` × warm sand `#D4C4A8`（accent only / アクセントのみ）
- **Typography / フォント:** Bebas Neue (display) × Outfit (body)
- **Aesthetic / 世界観:** architecture-studio portfolio × quiet luxury / 建築事務所ポートフォリオ × クワイエットラグジュアリー
- **UX:** extreme white space, 1px borders only, no decorative cursor, minimal animation, strictly enforced grid / 極端な余白・1pxボーダーのみ・装飾なし・アニメ最小限・厳格グリッド

## Tech / 技術
Pure HTML + CSS Custom Properties + Vanilla JS, Google Fonts CDN. No framework, no build step — GitHub Pages ready.

## Bundled assets / 同梱アセット
This skill folder is the reference implementation — start from these files:
- `index.html` — full page markup
- `style.css` — design tokens (CSS custom properties) + layout
- `script.js` — minimal vanilla JS
- `README.md` — full bilingual doc and series context

## How to apply / 適用方法
1. Use `style.css` custom properties (color/type/spacing tokens) as the design-system base; keep the white × near-black × warm-sand palette and the whitespace/1px-border discipline.
2. Copy `index.html` layout as the starting structure, then swap brand name and content. Keep the strict grid and minimal motion.
3. Pair Bebas Neue (display) with Outfit (body) via Google Fonts.

> "FORM" is a fictional brand for this study — replace all brand/content. Full context & the apparel persona series (trend/street/vintage/minimal): see **`README.md`**.
