# FORM — design-apparel-minimal

> **"Only what remains"**

A design study exploring a fictional youth apparel brand tailored to the **minimal persona** — quality-over-quantity, normcore, quiet luxury aesthetic, targeting Japanese design-minded individuals aged 20–26.

FORM is a fictional brand created for this design study. It is not a real brand, store, or product.

## Overview

| | |
|---|---|
| **Brand** | FORM |
| **Persona** | minimal |
| **Live Site** | [design.apparel-minimal.riumu.net](https://design.apparel-minimal.riumu.net/) |
| **Custom Domain** | `design.apparel-minimal.riumu.net` |

## Design Concept

- **Color**: Pure white `#FAFAFA` × near-black `#111111` × warm sand `#D4C4A8` (accent only)
- **Typography**: Bebas Neue (display) × Outfit (body)
- **Aesthetic**: Architecture studio portfolio × quiet luxury
- **UX**: Extreme white space, 1px borders only, no decorative cursor, minimal animation, grid strictly enforced

## Tech Stack

- Pure HTML + CSS Custom Properties + Vanilla JS
- Google Fonts CDN
- No framework, no build step — GitHub Pages ready
